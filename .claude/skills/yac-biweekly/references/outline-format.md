# Outline format

The outline is the one file the exec reads: a brief, plain list of topics. It is not a slide-by-slide spec. Save it as `biweekly/YYYY.MM.DD/outline.md`. Keep it to one screen.

```markdown
# YAC Biweekly — Wednesday, October 21 · 8:15–9:15 PM ET

1. **Opener** — Seven · 5 min
   [Opener prompt — Seven to supply]
2. **Teammate Tribute** — Akhil, for Kaavya · 3 min
3. **Announcements** — Seven · 4 min
   - Pickleball Open Play, Sun Nov 8, 2–4 PM
   - Halfway through provisional period: mid-semester check-ins
   - OKR mid-semester scores coming
   - Foundation reception recap — Nandhini
4. **Engagement app** — Jacob · 5 min
5. **Alumni Database** — Joshua · 5 min
   Version 1.0 rollout and training
6. **Social media update and ask** — Lily · 3 min
7. **YAC Families** — Lily · 8 min
   Fall gathering: budget, theme, breakouts
8. **The Catalyst Award** — Sam · 4 min
9. **Before we go** — Seven · 3 min
   Enneagram makeup · next biweekly Wed, Nov 4 · 8:15 PM

Buffer · 5 min

**Still open**
- Opener prompt (Seven)
- Teammate Tribute recipient
- Catalyst recipient and tagline
```

## Rules

- One line per topic: **bold name**, owner, minutes. Sub-lines only when they help the exec remember what is in it.
- Order is the order of the meeting, the same as the deck.
- Minutes add up to 60 with a Buffer line of 5–10.
- First names only (as in the Member Directory). No emails, no phone numbers.
- Leave out anything sensitive. Never write down a member stepping down, feedback about a person, or private check-in notes.
- Placeholders: `[what is needed — owner]`. Collect them under **Still open**.
- No design talk (colors, layouts, templates) and no slide numbers.
- If something is the first to cut when the meeting runs long, say so in one italic line under the buffer: *If we run long, cut the shareout first.*
